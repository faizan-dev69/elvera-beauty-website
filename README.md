# ELVÉRA — Luxury Beauty Brand Website

A modern, professional website for ELVÉRA beauty brand featuring elegant design and interactive elements.

## Features

- 🎨 Modern, elegant design with custom color palette
- 📱 Fully responsive for all devices
- ✨ Smooth animations and interactive elements
- 🖼️ High-quality image gallery with lightbox
- 📞 Contact section with functional form
- 🛍️ Product showcase with hover effects
